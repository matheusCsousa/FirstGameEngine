Fersa Editor - preview release

Extract the entire ZIP into a writable folder, then run fersa_editor.exe.
Keep the assets and licenses folders beside the executable.
Windows 10/11 x64 and an OpenGL 3.3 capable graphics driver are required.
No compiler or Python installation is needed.

Use + Add object in Hierarchy to create a cube, square, ground plane,
sphere, cylinder, cone, or capsule (bean). Objects appear four units in
front of the camera, with unique names and automatic selection.

W/E/R: move/rotate/scale tools. F: frame selection.
Hold right mouse + WASD to fly; Q/E down/up; Shift to move faster.
Use the Inspector to assign a texture, tint, physics, or Lua script.
Import OBJ, PNG/JPEG, or Lua via Assets or drag files onto the window.
Play runs a temporary copy. Stop restores the authored scene.
Ctrl+S saves; Save As copies project assets with the scene.
The default project folder is created beside the executable.

This is an experimental editor: save work regularly.
Squares and planes are flat 3D surfaces, not a separate 2D editor.
Physics uses bounding boxes for all shapes, including curved primitives.
The ZIP is unsigned; Windows may show an unknown publisher prompt.
